# FumboClientBeta

Hier erscheinen ausschließlich **Beta-Versionen** von FumboClient.

Stabile Releases bleiben im Haupt-Repository:
https://github.com/kingfabi3855/FumboClient

## Beta installieren

1. Passende Datei für deine Minecraft-Version herunterladen:
   - Minecraft 1.21.11: `FumboClient-…-mc1.21.11.jar`
   - Minecraft 26.3: `FumboClient-…-mc26.3.jar`
2. Minecraft schließen.
3. Die bisherige FumboClient-/hugosmp-lite-JAR im `mods`-Ordner ersetzen.
4. Nicht beide Varianten gleichzeitig installieren.

Die SHA-256-Prüfsummen stehen in `SHA256SUMS.txt` des jeweiligen Releases.

## Updates und Rückweg zu Stable

Ab FumboClient 1.26.0 erkennt der Client den Kanal an der installierten Version:

- **Installierte Beta** (`…-beta.N`): Update-Prüfung nutzt dieses Beta-Repository.
- **Stabile Version**: Update-Prüfung nutzt das stabile Repository.

Im Update-Menü:

- **Beta herunterladen** lädt die neueste Beta – auch aus einer stabilen Installation.
- **Zurück zu Stable herunterladen** erscheint nur bei installierter Beta und lädt
  die neueste stabile Version.
- Danach **Update installieren & Minecraft beenden** wählen und auf
  „Bitte starte Minecraft wieder.“ warten.

## Wichtig

- Betas können Fehler enthalten und Funktionen noch ändern.
- Beta-Releases werden nie als „Latest“ im stabilen Repository markiert.
- Es werden nur Binärdateien, Prüfsummen und Lizenzhinweise veröffentlicht,
  kein Quellcode.
- Kein offizielles Minecraft-Produkt. Nicht von Mojang/Microsoft genehmigt oder
  mit ihnen verbunden.
